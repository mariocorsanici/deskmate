# Agent guidance

## Agent skills

### Issue tracker

Issues and specs are tracked locally as Markdown under `.scratch/`. Read `docs/agents/issue-tracker.md` when creating, publishing, triaging, or implementing specs and tickets.

### Triage labels

The tracker uses the default triage vocabulary. Read `docs/agents/triage-labels.md` when triaging issues or changing their status.

### Domain docs

This is a single-context repository. Read `docs/agents/domain.md` when exploring domain concepts, updating the glossary, recording decisions, or checking a change against existing decisions.
